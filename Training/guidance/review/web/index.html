Quick labeling guide
Speed
Read complete HUD digits. Cropped or unclear digits are unknown, not zero. Entering a value links it to the displayed frame.
Direction & target
Use the current corner when clearly negotiating it; otherwise the next visible bend. A straight visible segment is not a claim about the whole future route.
Phase
Approach: before entry. Entry: beginning the curved path. Apex region: visibly passing the corner’s interior region. Exit: leaving as the path opens. Transition: changing between connected bends. Use unknown if this history is insufficient.
Evidence
A minimap can show a bend without establishing phase. Slowing does not prove braking. Don’t use outside knowledge or later footage to fill gaps.
